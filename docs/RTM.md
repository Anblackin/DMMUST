# 需求跟踪矩阵（RTM）

负责人角色：产品经理

本矩阵将主要需求映射到实现模块、后端接口、前端页面和测试验证项。

| 需求编号 | 需求描述 | 业务模块 | 后端接口 | 前端页面/功能 | 测试验证 |
|---|---|---|---|---|---|
| R1 | 学生注册与登录 | 用户管理 | `POST /api/user/register`, `POST /api/user/login` | 登录/注册页面 | 注册成功、登录成功、错误提示 |
| R2 | 个人信息填写与修改 | 用户管理 | `GET /api/user/info`, `POST /api/user/updateInfo` | 个人信息页 | 信息加载、修改保存、权限校验 |
| R3 | 起床打卡统计 | 记录管理 | `/api/record` 系列接口 | 起床打卡页面 | 打卡记录创建、分页显示、数据统计 |
| R4 | 晚归登记统计 | 记录管理 | `/api/record` 系列接口 | 晚归登记页面 | 晚归登记保存、审核与查询 |
| R5 | 宿舍打扫记录 | 清洁记录 | `/api/cleaner`、`/api/record` | 打扫记录页面 | 打扫记录 CRUD、数据展示 |
| R6 | 宿舍楼层管理 | 建筑管理 | `/api/building`, `/api/floor`, `/api/room` | 楼层管理页面、房间维护页面 | 楼层/房间创建、编辑、删除、查询 |
| R7 | 宿舍评价管理 | 评价模块 | `/api/evaluate` | 评价列表与详情页面 | 评价提交、历史记录、评分计算 |
| R8 | 学生信息查看 | 管理端 | `/api/user/getStudents`, `/api/user/getStudentInfoByIdOrAccount` | 学生管理列表页 | 关键字段显示、筛选、搜索 |
| R9 | 管理员与超级管理员管理 | 用户权限 | `/api/user/getAdminTableData`, `/api/user/addAdmin` | 管理员管理页面 | 权限校验、超级管理员专属操作 |
| R10 | 舍友管理与宿舍分配 |  roommate 功能 | 后端用户与房间关联接口 | 舍友匹配页 | 舍友分配、宿舍同步显示 |
| R11 | 数据统计与报表展示 | 仪表盘 | 综合接口汇总 | 仪表盘、统计页面 | 统计数据准确、趋势图显示 |
| R12 | UI 主题与学校风格定制 | 样式定制 | 无 | 全局样式、主题组件 | 视觉一致性、主题色验证 |

## 备注

- 所有私有接口均受 JWT 认证保护，需在前端请求中带上 Token。
- `GET /api/user/info` 是前端获取当前登录用户信息的核心接口。
- 评价、记录、清洁等模块需确保数据关联到宿舍、楼层和学生。
- 若发现新业务需求，应补充此矩阵并更新测试用例。
