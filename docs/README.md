# 项目工程文档总览

本目录包含为 DMMUST 项目生成的核心工程文档。每份文档已注明负责人角色。

- `WBS.md`：工作分解结构，负责人为项目经理
- `RTM.md`：需求跟踪矩阵，负责人为产品经理
- `Quality-Metrics.md`：质量指标，负责人为测试工程师
- `RMMM.md`：风险缓解、监控与管理计划，负责人为项目经理
- `Estimation-Model.md`：估算模型、软件方程、最小时间、PNR 曲线，负责人为技术负责人
- `Task-Set-Network.md`：任务集网络，负责人为项目经理
- `Earn-Value-and-Decision-Tree.md`：挣值分析与决策树，负责人为项目经理
- `Leangoo-Storyboard.md`：Leangoo 故事板内容，负责人为产品经理
- `GitHub-Timeline.md`：GitHub 时间线说明，负责人为运维工程师
- `Presentation-Config-Change-Management.md`：配置管理与变更管理演示材料，负责人为运维工程师

## 使用说明

1. 先阅读 `docs/README.md` 了解文档结构。 
2. 按照项目阶段依次查看 `WBS.md`、`Task-Set-Network.md`、`Estimation-Model.md`。
3. 将 `RTM.md` 与 `Quality-Metrics.md` 作为需求验证和测试基准。
4. `RMMM.md` 用于推进风险控制与管理决策。
5. `GitHub-Timeline.md` 用于归档当前仓库分支、提交与测试状态。
