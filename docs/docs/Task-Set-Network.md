# 任务集网络（Task Set Network）

负责人角色：项目经理

## 1. 关键任务清单

| 任务编号 | 任务名称 | 说明 | 前置任务 |
|---|---|---|---|
| T1 | 需求确认与分析 | 完成学生端与管理端功能清单 | - |
| T2 | 架构设计与数据建模 | 设计前端路由、后端 API、数据库模型 | T1 |
| T3 | 后端基础服务搭建 | 搭建 Koa、JWT、Sequelize、路由加载 | T2 |
| T4 | 用户管理模块 | 注册、登录、用户信息更新 API | T3 |
| T5 | 宿舍楼层管理模块 | 构建宿舍楼、楼层、房间管理 API | T3 |
| T6 | 记录与评价模块 | 起床、晚归、清扫、评价等接口 | T3 |
| T7 | 前端基础搭建 | Vue 项目、路由、Vuex、主题样式 | T2 |
| T8 | 学生端 UI 开发 | 登录、个人页、打卡、统计页面 | T7, T4, T6 |
| T9 | 管理端 UI 开发 | 楼层管理、用户管理、评价分析页面 | T7, T5, T6 |
| T10 | 前后端联调 | 验证接口契约与数据流 | T4, T5, T6, T8, T9 |
| T11 | 测试与缺陷修复 | 单元测试、集成测试、回归测试 | T10 |
| T12 | 部署与验收 | 生产构建、部署、用户验收 | T11 |

## 2. 网络依赖描述

- **T1 → T2**：需求分析完成后才能确定系统架构和数据模型。
- **T2 → T3、T7**：后端与前端基础工作均依赖整体架构设计。
- **T3 → T4、T5、T6**：后端基础服务搭建完成后，各业务模块开始实现。
- **T7 → T8、T9**：前端基础搭建后才能进入学生端与管理端开发。
- **T4、T5、T6、T8、T9 → T10**：所有核心模块开发完成后进入联调阶段。
- **T10 → T11 → T12**：联调完成后进行测试与部署。

## 3. 关键路径分析

关键路径任务为：

`T1 → T2 → T3 → T4 → T8 → T10 → T11 → T12`

其中 `T8`（学生端 UI 开发）与 `T4`（用户管理模块）为关键路径上的核心任务，因为学生端为系统主要使用场景。

## 5. 节点与里程碑

- **M1 需求与设计完成**：T1、T2 完成
- **M2 后端基础与关键接口完成**：T3、T4、T5、T6 完成
- **M3 前端基础与页面初版完成**：T7、T8、T9 完成
- **M4 联调与测试完成**：T10、T11 完成
- **M5 部署与交付完成**：T12 完成

## 6. 重点控制点

- 任务 `T2` 需要尽早完成，避免后续设计返工。
- `T3` 应与 `T7` 并行推进，保证前后端开发节奏一致。
- `T10` 是进度风险最高的阶段，应设置至少一轮回归测试。
- `T11` 所得缺陷必须快速闭环，避免影响 `T12` 发布。
