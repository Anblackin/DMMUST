# 工作分解结构（WBS）

负责人角色：项目经理

## 1. 项目管理

1.1 项目启动与规划
- 1.1.1 收集需求与评审
- 1.1.2 确定角色与交付标准
- 1.1.3 制定里程碑和发布计划

1.2 进度与沟通管理
- 1.2.1 日常站会与周报
- 1.2.2 风险评审与问题跟踪
- 1.2.3 变更控制与审批

1.3 质量控制
- 1.3.1 质量指标定义
- 1.3.2 测试计划与用例评审
- 1.3.3 测试执行与缺陷跟踪

## 2. 需求分析与产品设计

2.1 需求分析
- 2.1.1 学生端功能需求分析
- 2.1.2 后台管理端功能需求分析
- 2.1.3 UI/UX 与交互需求汇总

2.2 原型与系统设计
- 2.2.1 前端页面结构设计
- 2.2.2 后端 API 设计与路由定义
- 2.2.3 数据库 ERD 与模型设计

## 3. 后端开发

3.1 系统搭建与基础支撑
- 3.1.1 Koa 服务搭建
- 3.1.2 JWT 登录认证与权限中间件
- 3.1.3 MySQL / Sequelize 数据库初始化

3.2 用户与身份管理模块
- 3.2.1 注册与登录接口
- 3.2.2 用户信息查询与更新接口
- 3.2.3 管理员与超级管理员权限管理

3.3 宿舍与楼层管理模块
- 3.3.1 宿舍楼管理 API
- 3.3.2 楼层管理 API
- 3.3.3 房间管理 API

3.4 记录与评价模块
- 3.4.1 起床与晚归记录管理
- 3.4.2 宿舍清洁打扫记录管理
- 3.4.3 宿舍评价与评分管理

3.5 统计与查询模块
- 3.5.1 学生数据查询接口
- 3.5.2 管理员数据列表接口
- 3.5.3 学生宿舍/楼层/房间筛选查询

## 4. 前端开发

4.1 基础前端架构
- 4.1.1 Vue 项目初始化与环境配置
- 4.1.2 路由设计与权限拦截
- 4.1.3 Vuex 状态管理设计

4.2 学生端视图开发
- 4.2.1 登录 / 注册页面
- 4.2.2 个人信息页面
- 4.2.3 起床打卡、晚归登记、打扫记录页面
- 4.2.4 数据展示与统计视图

4.3 管理端视图开发
- 4.3.1 管理员控制台与仪表盘
- 4.3.2 楼层 / 宿舍 / 房间管理页面
- 4.3.3 用户管理与权限分配页面
- 4.3.4 宿舍评价与数据分析页面

4.4 UI 定制与体验优化
- 4.4.1 主题颜色与样式调整
- 4.4.2 组件复用与交互一致性
- 4.4.3 响应式布局与兼容性调整

## 5. 测试与验收

5.1 单元测试与组件测试
- 5.1.1 前端 Jest 单元测试
- 5.1.2 后端接口单元测试设计（手动/自动）

5.2 集成测试
- 5.2.1 前后端联调验证
- 5.2.2 登录、权限、数据流完整性测试
- 5.2.3 页面功能端到端验收

5.3 UAT 与发布验收
- 5.3.1 关键功能用户验收
- 5.3.2 Bug 修复与回归验证
- 5.3.3 线上部署准备与发布说明

## 6. 部署与运维

6.1 本地与开发环境部署
- 6.1.1 前端 `npm run dev`
- 6.1.2 后端 `npm run dev`
- 6.1.3 数据库初始化 `npm run db:init`

6.2 生产环境部署
- 6.2.1 生产构建与静态文件发布
- 6.2.2 后端服务 `npm start`
- 6.2.3 日志与错误监控

6.3 维护与迭代
- 6.3.1 版本发布与分支管理
- 6.3.2 持续集成与代码审查
- 6.3.3 需求迭代与遗留问题跟踪
